## MDX

Files ending in `.mdx` can also use JavaScript expressions and components, e.g. this post was built in {new Date().getFullYear()}.

## Drafts

Set `draft: true` in the front matter to keep a post out of the live site. It still shows up when you run `npm run dev`.
